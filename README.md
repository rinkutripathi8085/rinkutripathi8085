### Projects

#### AI-Based Full Stack Medical Assistant  
🔗 [GitHub Repository](https://github.com/rinkutripathi8085/rinku_your_personal_medical__assistant)  
- Built an AI-powered chatbot using **FastAPI** and **OpenAI** that allows users to input symptoms (text/voice) and receive diagnostic suggestions.  
- Integrated **MongoDB** to persist patient sessions and ensure continuity in follow-up interactions.  
- Applied prompt engineering and safety guardrails to minimize hallucinations and risky responses from the LLM.  

---

#### ATS Score Checker  
🔗 [GitHub Repository](https://github.com/rinkutripathi8085/Resume_ATS_Cheker)  
- Developed a resume evaluation system using **FastAPI** and **OpenAI** that parses and scores resumes based on recruiter-friendly criteria.  
- Provides real-time improvement suggestions (formatting, keywords, section optimization) using GPT.  
- Designed RESTful APIs to integrate with larger job portals or resume-builder tools.  

---

#### AgroVision – Smart Farming Assistant  
🔗 [GitHub Repository](https://github.com/rinkutripathi8085/AgroVision_plants)  
- Created a multilingual farming assistant that uses **GPT** to interpret colloquial inputs from farmers and return precise crop or pesticide suggestions.  
- Built a scalable **FastAPI** backend with planned modules for image-based leaf disease detection using ML models.  
- Added offline support via caching mechanisms to enable use in low-connectivity rural areas.
